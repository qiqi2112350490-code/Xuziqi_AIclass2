一

一线之界

单层感知机的全部本领，是在平面上画一条直线。先亲手把这条线挪到无路可走。

异或的四个样本摆在正方形的四个角：(0,0) 与 (1,1) 该输出 0， (0,1) 与 (1,0) 该输出 1。同类点坐在对角，异类点互相挨着。 下面这条线由三个数决定——w₁、w₂ 管方向，b 管平移。 你可以拖动滑块去找，也可以让机器替你穷举十万条。

读法 一条线的全部自由度

w₁、w₂ 是这条线的法向量，决定它朝哪边斜；
b 决定它离原点多远，正负号决定往哪一侧偏；
z ≥ 0 判 1，z < 0 判 0。
三个数一起调，能画出平面上所有直线——也只有直线。

＊ 穷举是对 (w₁, w₂, b) 做十万次随机采样后取最优——最好的结果也只有 75%，因为四个点对角分布，任何一条直线都必然切错一对。

二

折地成界

既然一条线不够，就让隐藏层先把输入组合成两个中间特征，再在中间特征上划线。

讲义把异或写成 (x₁ ∧ ¬x₂) ∨ (¬x₁ ∧ x₂)：要么「有其一而无其二」，要么反过来。 于是给网络配两位门客——
甲：只看 x₁ 有、x₂ 无，这类情况举手；乙：只看 x₂ 有、x₁ 无，那类情况举手。最后由输出层合议：谁举手都算通过。 数学上，这两句话就是两条平行的斜线，把平面切成三条带子；四个点被搬到 h₁–h₂ 平面后，一条直线就能分开。 不过要留意：输出层的 v、b₀ 初值把门槛设在 0.833，偏高了，所以一开始还差一个点判错——把门槛挪到 0.6 附近才全对，这正是训练要做的事。

      两段代码从同一个起点出发（W = [[2,−2],[−2,2]]、b = [−1,−1]、v = [3,3]、b₀ = −2.5），走同一条 Adam 路径。
      300 轮之后，PyTorch 的损失是 0.02806528，TensorFlow 是 0.02806622；逐轮最大差 6.6×10⁻⁶（出现在第 49 轮），
      四个样本的输出概率在六位小数上完全一致，预测同为 0 1 1 0。
      这点差别来自两处：两个框架的 Adam 默认 eps 不同（1e-8 与 1e-7），以及浮点运算的先后次序不同。
    

    

      而上面那台网页训练台，与这份 PyTorch 记录逐轮完全相同——300 轮的损失最大偏差 0.0。
      因为它不是「模拟」：同一组公式、同样的双精度浮点，前向、反向与 Adam 都在浏览器里真算一遍。
      这也说明一件事：框架换的是写法，不是数学；真正决定结果的是结构、初值、优化器与学习率这些更朴素的选择。
    

  


  


  
  

    

      六
      

        
做完之后，留下三条

        
不是结论，是这次动手换来的、下次能直接用的经验。

      

    

    

      

        其一
        
隐藏层不是「多一层」，是换坐标系

        
它把线性不可分的问题搬到另一个空间里，让那里存在一条能分开的直线。XOR 是两个半平面的「或」，这就是它的几何含义。

      

      

        其二
        
九个参数也够看一场完整的戏

        
张量、前向、损失、求梯度、更新——五件事在 2—2—1 上全部出现，一步不少。网络再大，流程也是这五步的放大。

      

      

        其三
        
可视化不是装饰，是诊断

        
损失曲线停住、边界再也不动，说明卡在平台或局部极小；换初值、调学习率，比盯着数字瞎猜有效得多。
